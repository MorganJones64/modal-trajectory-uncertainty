# mode-trajectory-uncertainty

Examples of computing mode-trajectory uncertainty for fluid flow in two dimensions.

**Journal article:** https://journals.aps.org/prfluids/abstract/10.1103/kgw4-ywtm  
**Preprint:** https://arxiv.org/abs/2410.20802

The repository consists of four examples:
- crossflow model
- cylinder wake
- oscillating foil wake (in-progress)
- turbulent channel flow (in-progress)
